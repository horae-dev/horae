# Changelog

All notable changes to Horae (the `horae` package and the `ghcr.io/horae-dev/horae` image), newest
first. Versions follow [Semantic Versioning](https://semver.org/). Each section is generated from
the merged pull requests by `scripts/changelog.sh`, grouped by label (`.github/release.yml`), and
becomes the body of the GitHub Release. See [docs/operations/releasing.md](docs/operations/releasing.md).

The `horae-sdk` package is released separately (`sdk-v*` tags).
